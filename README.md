# Game Dev Duo

## Future Building Collection

Create a distinctive collection of buildings for the game world. Each building should have a strong silhouette, a memorable identity, and modular parts that can be reused across different locations.

### Collection Direction

- Combine practical architecture with unusual shapes, colors, and details.
- Design buildings that are recognizable from a distance and interesting up close.
- Keep the collection visually cohesive while giving every building its own story.
- Build assets in modular pieces so they can be rearranged, upgraded, and reused.

### Building Ideas

- A compact workshop with rooftop machinery
- A bright neighborhood market
- An old observatory or research tower
- A small transit station
- A dramatic central landmark
- Utility buildings, homes, and shops to fill out the world

### Future Asset Checklist

- Define the building's purpose and visual identity.
- Block out the primary silhouette in Blender.
- Create reusable walls, roofs, windows, doors, and props.
- Add materials, lighting details, and signs that support the building's story.
- Prepare simple and detailed versions for performance and gameplay needs.
